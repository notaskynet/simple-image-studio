# simple-generation-page

Одностраничное веб-приложение для генерации изображений по текстовому описанию через API.

## Возможности

- Генерация по промпту (Ctrl/Cmd + Enter), формат 1:1, 3:2, 2:3, от 1 до 4 изображений за раз.
- Стили-пресеты: фото, аниме, акварель, 3D, пиксель-арт, минимализм.
- Отмена генерации, таймер, скелетоны нужных пропорций.
- Действия с изображением: скачать, копировать изображение или промпт, повторить, вариации, избранное, удалить.
- Полноэкранный просмотр с листанием стрелками и свайпом.
- История в IndexedDB с поиском и фильтром «Только избранное».
- Тёмная и светлая темы, адаптивная вёрстка.

## API-ключ

Ключ вводится в приложении и хранится **только в localStorage вашего браузера**. В репозитории и коде его нет.
Удалить ключ из браузера можно в настройках кнопкой «Забыть ключ».

> ⚠️ Никогда не публикуйте свой API-ключ: не коммитьте его в репозиторий, не вставляйте в issues, скриншоты и чаты.

## Локальный запуск

```bash
npm install
npm run dev
```
